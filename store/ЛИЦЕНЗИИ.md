# Лицензии и сторонние компоненты

Этот файл нужен для карточки приложения в Microsoft Store и для соблюдения
лицензий сторонних библиотек.

## Собственный код приложения

Код «Нарезки Shorts» — ваш. Если планируете распространять его публично,
добавьте сюда текст выбранной лицензии (например, MIT) и укажите автора.

## ffmpeg (GPL) — важно при распространении

Приложение использует **ffmpeg** из пакета `imageio-ffmpeg`. Поставляемый там
бинарник собран с включённым GPL, поэтому:

* в описании приложения нужно указать, что внутри используется ffmpeg;
* нужно дать ссылку на исходный код ffmpeg и текст лицензии GPL;
* нельзя распространять приложение как проприетарное, скрывая этот факт.

Ссылки:

* ffmpeg — <https://ffmpeg.org/> , лицензия: <https://ffmpeg.org/legal.html>
* исходный код: <https://ffmpeg.org/download.html#get-sources>
* пакет-обёртка: <https://github.com/imageio/imageio-ffmpeg> (BSD-2)

Готовая формулировка для карточки приложения:

```
Приложение использует ffmpeg (https://ffmpeg.org) под лицензией GPL v3.
Исходный код ffmpeg доступен на https://ffmpeg.org/download.html#get-sources.
ffmpeg поставляется вместе с приложением и работает локально.
```
