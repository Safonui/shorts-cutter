# Политика конфиденциальности — «Нарезка Shorts»

Дата последнего обновления: 21 ноября 2026 года.

## Коротко

Приложение «Нарезка Shorts» работает на вашем компьютере, **не собирает и не
передаёт никаких данных** о вас и о ваших файлах. Всё, что оно делает, остаётся
на вашем устройстве.

## Какие данные обрабатываются

* **Видеофайлы, которые вы выбираете.** Приложение читает их локально, чтобы
  показать длительность, разрешение и кадровую частоту, а затем нарезать клипы.
  Файлы никуда не отправляются.
* **Настройки приложения** (формат вывода, качество, папка вывода, размер и
  положение субтитров). Хранятся в файле `settings.json` в папке
  `%APPDATA%\ShortsCutter` на вашем компьютере.
* **Журнал работы** `shorts_cutter.log` рядом с программой: время запуска,
  параметры обработки и коды возврата. Файл создаётся только на вашем диске и
  нужен для разбора ошибок.

Никакие персональные данные, телеметрия, идентификаторы устройства, история
использования и содержимое ваших видео не собираются и не передаются.

## Обращение к интернету

Приложение работает офлайн. Единственное обращение к сети происходит, если вы
включите субтитры: при первом использовании загружается модель распознавания речи
(faster-whisper «small», ориентировочно 460 МБ) с сайта Hugging Face
(`huggingface.co`). Дальше распознавание идёт офлайн. Если субтитры не включать,
интернет не нужен вовсе. Установка самого приложения из Microsoft Store
выполняется средствами Store и подчиняется политике конфиденциальности Microsoft.

## Третьи стороны

* **ffmpeg** (через пакет `imageio-ffmpeg`) — используется локально для обработки
  видео, лицензия GPL, исходники: <https://ffmpeg.org/download.html>.
* **faster-whisper** — необязательный модуль распознавания речи, выполняется
  локально после загрузки модели, лицензия MIT.

Перечисленные компоненты не собирают данные и не передают их разработчику
приложения.

## Дети

Приложение не предназначено для сбора данных о детях и не собирает данные ни о
ком.

## Изменения политики

Актуальная версия политики публикуется по этому же адресу. При изменениях
обновляется дата в начале документа.
