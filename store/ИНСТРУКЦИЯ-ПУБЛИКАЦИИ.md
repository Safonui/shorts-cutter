# Публикация в Microsoft Store: пошагово

Приложение подготовлено к отправке: манифест, графика, тексты и скрипт сборки
пакета лежат в проекте. Подпись для Store делает сама Microsoft — свой
сертификат подписи кода не нужен, и именно поэтому этот путь обходит блокировку
Smart App Control на вашем компьютере.

## 1. Что нужно от вас один раз

| Что | Где взять | Зачем |
| --- | --- | --- |
| Аккаунт Partner Center | <https://partner.microsoft.com/dashboard> — регистрация как индивидуальный разработчик, разовый платёж ~$19 | без него не отправить приложение |
| Имя приложения | там же: **Apps → New product → MSIX or PWA app**, зарезервировать название «Нарезка Shorts» | имя закрепляется за вами |
| **Publisher из аккаунта** | Partner Center → **Account settings → Publisher** (строка вида `CN=Иван Иванов`) | он обязан совпадать с манифестом пакета |
| Ссылка на политику конфиденциальности | любой хостинг: GitHub Pages, Google Docs (опубликованный), свой сайт | Store требует URL; текст готов в `ПОЛИТИКА-КОНФИДЕНЦИАЛЬНОСТИ.md` |

## 2. Сборка пакета

```bat
.venv\Scripts\python.exe make_icon.py                    :: если ещё не делали
.venv\Scripts\python.exe make_store_package.py --publisher "CN=Иван Иванов"
```

Скрипт сам скачает официальный `makeappx.exe`, соберёт папку приложения и упакует
её в `store\dist\ShortsCutter_1.0.0.0_x64.msix`, затем проверит пакет.

**Если makeappx не запускается** (ошибка 14001, «неправильная параллельная
конфигурация») — на компьютере повреждён распространяемый пакет Visual C++.
Варианты по возрастанию усилий:

1. **Собрать пакет на чистом компьютере через GitHub Actions** (самый простой
   путь, если править систему не хочется): в проекте уже лежит
   `.github/workflows/build-msix.yml`. Загрузите проект в свой репозиторий на
   GitHub, откройте вкладку **Actions → Сборка MSIX для Microsoft Store →
   Run workflow**, укажите издателя из Partner Center — через несколько минут
   готовый `.msix` появится в артефактах сборки. Никаких установок на вашем
   компьютере не требуется.
2. Восстановить компоненты Windows (от имени администратора):
   `DISM /Online /Cleanup-Image /RestoreHealth`, затем повторить
   `winget install --id Microsoft.VCRedist.2015+.x64 --force`.
3. Собрать пакет на другом компьютере: скопировать проект и запустить
   `make_store_package.py --publisher "CN=..."` там.

Остальные части приложения от этого не зависят.

## 3. Отправка

1. Partner Center → ваше приложение → **Start submission**.
2. **Packages**: загрузите `store\dist\ShortsCutter_1.0.0.0_x64.msix`.
   Если Partner Center предложит `.appxupload` — можно загрузить и один `.msix`,
   требование об `.appxupload` появилось только для сборок с символами.
   Дождитесь проверки: пакет должен пройти валидацию без ошибок.
3. **Store listing**: заполните тексты из `ОПИСАНИЕ.md`
   (краткое описание, полное описание, ключевые слова, что нового),
   загрузите скриншоты (готовые — в `screenshots/`), выберите категорию
   «Аудио и видео» и укажите ссылку на политику конфиденциальности.
4. **Age ratings**: пройдите опрос IARC. Приложение не содержит пользовательского
   контента, рекламы и покупок — везде «нет». Ожидаемая категория: 3+.
5. **Pricing and availability**: «Бесплатно», рынки — можно все.
6. **Properties**: категория «Аудио и видео» → «Редактирование видео»,
   поддержка — ваша почта, «Это приложение использует …» — отметьте
   `runFullTrust` (полное доверие), если спросят.
7. **Submit** → проверка обычно занимает от нескольких часов до пары дней.

## 4. Про лицензии и содержимое пакета

* Внутри приложения используется **ffmpeg** из пакета `imageio-ffmpeg` — сборка
  под лицензией **GPL**. При публикации нужно указать это и дать ссылку на
  исходники: <https://ffmpeg.org/download.html> и
  <https://github.com/imageio/imageio-ffmpeg>. Текст для карточки приложения
  есть в `ЛИЦЕНЗИИ.md`.
* Субтитры (`faster-whisper`) в пакет **не входят**: модель ~460 МБ, её нельзя
  кладть в пакет Store. Приложение скачивает её при первом включении субтитров
  и дальше работает офлайн. В описании это указано.
* Приложение ничего не собирает о пользователе и не отправляет данные —
  это отражено в политике конфиденциальности.

## 5. Обновления версии

1. Поднимите версию в `appconfig.py` (`APP_VERSION = "1.0.1"`).
2. Пересоберите пакет: `make_store_package.py --publisher "CN=..."`.
3. В Partner Center → **Update** → загрузите новый `.msix` и опишите изменения
   в `ОПИСАНИЕ.md` (раздел «Что нового»).
