# Тексты для карточки в Microsoft Store

Готовые тексты: копируются в Partner Center → Store listing. Ничего придумывать
не нужно, но можно поправить под себя.

## Название

```
Нарезка Shorts
```

## Краткое описание (до 100 символов)

```
Режет длинное видео на вертикальные клипы 9:16, вшивает субтитры
```

## Полное описание

```
«Нарезка Shorts» превращает длинное видео — подкаст, интервью, влог, стрим — в
готовые вертикальные клипы 9:16 для YouTube Shorts и TikTok. Ничего не нужно
устанавливать дополнительно: ffmpeg уже внутри приложения.

ЧТО УМЕЕТ

• Разметка интервалов: ввод строкой (1:23-2:45 или 01:23:45-01:25:00) или через
  поля «Начало» и «Конец».
• Проверка интервалов: конец раньше начала, выход за пределы видео, пересечения
  между клипами — ошибочные строки подсвечиваются.
• Вертикальный кроп 9:16 (1080×1920): центральный кроп считается по реальному
  кадру, поэтому даже 4K-источник обрабатывается быстро.
• Прогресс и отмена: видно процент по каждому клипу, обработку можно прервать —
  частичный файл удаляется, приложение остаётся рабочим.
• Аккуратные имена файлов: ролик_клип01.mp4, _клип02 … без перезаписи
  существующих файлов (добавляется суффикс _2, _3).
• «Нарезать подряд»: видео автоматически разбивается на равные клипы заданной
  длины — когда размечать вручную не хочется.
• Поиск ярких моментов по звуку: приложение находит места, где происходит
  что-то заметное — смех, крик, аплодисменты, резкие всплески, — и показывает,
  почему выбрало именно их.
• Субтитры (опционально): распознавание речи через faster-whisper, вшивание
  текста в клип. Настройки: размер, положение (низ или центр), цвет (белый или
  жёлтый), обводка всегда чёрная — текст читается на вертикальном кадре.
• Журнал работы: каждая команда обработки и её результат записываются в файл
  shorts_cutter.log.

КАК ЭТО РАБОТАЕТ

1. Выберите видеофайл — приложение покажет длительность, разрешение и частоту
   кадров.
2. Отметьте интервалы или нажмите «Нарезать подряд» / «Найти яркие моменты».
3. Нажмите «Нарезать» — клипы появятся в папке Shorts рядом с исходным видео.

ПРИВАТНОСТЬ

Приложение работает офлайн и ничего не отправляет в интернет. Единственное
обращение к сети — загрузка модели распознавания речи при первом включении
субтитров (её можно не включать).

ЧЕГО НЕТ В ЭТОЙ ВЕРСИИ

Загрузка клипов в YouTube/TikTok, автоматический выбор лучших фрагментов по
смыслу и пакетная обработка нескольких файлов сразу. Автодетект лица оставлен
на будущее — место в настройках помечено «позже».

ТЕХНИЧЕСКИЕ ДЕТАЛИ

• Только Windows 10/11 (64-бит), права администратора не нужны.
• Зависимости не требуются: ffmpeg поставляется вместе с приложением.
• Субтитры требуют одноразовой загрузки модели ~460 МБ и работают офлайн.
```

## Дополнительные поля

* **Категория:** Аудио и видео → Редактирование видео
* **Возрастной рейтинг:** 3+ (нет контента для взрослых, реклам, покупок)
* **Цена:** бесплатно
* **Поддержка:** ваша почта (укажите в Partner Center)
* **Конфиденциальность:** ссылка на `ПОЛИТИКА-КОНФИДЕНЦИАЛЬНОСТИ.md`, размещённую
  в интернете
* **Скриншоты:** готовые снимки лежат в `../screenshots/`
  (`01-main-window.png`, `02-settings.png`, `03-interval-check.png`,
  `04-готовый-клип.png`). Для Store нужны изображения 1366×768 или больше —
  снимки окна подходят, при необходимости можно дополнить кадром из `демо-клип.mp4`.
